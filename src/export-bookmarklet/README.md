# Conversations History Export Bookmarklet

This bookmarklet will export all your locally stored conversations as a JSON file.

## How to Use It

Add this as a new bookmarklet to your web browser.

```javascript
javascript:(async function(){const dbName='savedAIChatData';const maxImageBytes=25*1024*1024;const toBase64=async b=>{const u=new Uint8Array(await b.arrayBuffer());let s='';const C=0x8000;for(let i=0;i<u.length;i+=C)s+=String.fromCharCode.apply(null,u.subarray(i,i+C));return btoa(s)};const encodeFile=async f=>{const toBase64(f)}};try{const data=await new Promise((resolve,reject)=>{const req=indexedDB.open(dbName);req.onerror=()=>reject(new Error('Failed to open: '+req.error));req.onsuccess=async e=>{const Promise.all(stores.map(s=>new Promise((res,rej)=>{const os=tx.objectStore(s);const r=os.getAll();r.onsuccess=()=>{exp.stores[s]={keyPath:os.keyPath,autoIncrement:os.autoIncrement,indexes:Array.from(os.indexNames).map(i=>{const x=os.index(i);return{name:x.name,keyPath:x.keyPath,unique:x.unique,multiEntry:x.multiEntry}}),data:r.result};res()};r.onerror=()=>rej(new Error('Failed: '+r.error))})));let The next time you visit Duck.ai, click it to download a JSON file containing all your conversations from that browser.
```
